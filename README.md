# PILOTA DVR – app sopralluoghi

App web installabile (PWA) per i sopralluoghi di uno studio di sicurezza sul lavoro.
Legge e scrive liste e file di SharePoint tramite Microsoft Graph, con l'accesso dell'account Microsoft 365 dell'utente.

- Nessun server e nessun dato nel codice: i dati restano in SharePoint e sono visibili solo agli utenti autorizzati.
- Funziona anche senza rete: dati e bozze restano sul dispositivo e si inviano al ritorno della connessione.
- Prova senza accesso: aggiungere `?esempio` all'indirizzo (dati inventati).
